Rules: model weights and trust

Each upcoming selection starts from the bookmaker's no-margin probability (Pinnacle's for the game winner, Bet365's own for quarters and halves). The model then moves it by trust times its fitted view, never by more than the limit shown. Weight multipliers scale each fitted component (1 = as fitted, 0 = off). Trust comes from how the model did against Bet365 prices so far and is re-set at each daily build.
